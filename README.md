# 言笺 KotoNote

中日英专业术语背诵与便签本（内置 187 条测试与硬件、显示面板与光学触控等领域术语），支持严格按假名朗读、Excel 文档导入、锁屏与后台连续播放、本地音频缓存与移动端全屏使用。

本仓库包含最新的两个版本（**v4 锁屏后台播放版**）：

## 目录结构

- **`static/`** — 纯静态单文件离线版（源自 `kotonote-static-v4.html`）
  - 数据保存在浏览器本地数据库（IndexedDB），支持导入 `.xlsx / .xls / .csv / .tsv`。
  - 支持「🔒 锁屏音频」模式（默认连接热铁盒免费 TTS 代理，带 JSONP 跨域兜底；也支持微软 Azure 直连）与「📱 系统语音」离线模式，已播音频自动缓存至本地。

- **`retiehe/`** — 热铁盒网页托管版（源自 `kotonote-retiehe-v4`）
  - 前端 + 热铁盒 Python 云函数（`api/kotonote.py`）+ 热铁盒内置 KV 数据库（`kotonote_db`），支持手机与电脑多端实时云端同步。
  - 后端内置零受限模块依赖的 `action=tts` 语音接口（免费有道/百度双通道自动兜底，可选接入微软 Azure 神经网络语音），前端通过单 `<audio>` 无缝整词拼接 + 预加载下一词 + `MediaSession` 锁屏/耳机控制，支持 iPhone / 安卓 切后台与锁屏连播。
  - 部署方式见 [`retiehe/热铁盒上传说明.txt`](retiehe/热铁盒上传说明.txt)。

## v4 核心特性

1. **锁屏与后台连续背词**：将每条术语的 `日×2 → 0.85s 停顿 → 中 → 语种停顿 → 英 → 词间停顿` 无缝合成为连续音频流，边播边预加载下一词，配合锁屏媒体卡片支持切后台、锁屏与蓝牙耳机切词。
2. **严格按假名朗读日语**：优先读独立假名列，自动识别双行假名与行内括号注音。
3. **原生 Excel 词库导入**：纯前端解析 `.xlsx / .csv / .tsv`（支持多工作表、列映射、前 5 条预览、追加合并或清空替换）。
4. **本地音频缓存**：播放过的词条语音自动缓存至手机 IndexedDB，二次复习零流量、断网也能锁屏播。

## 快速使用

### 1. 纯静态版
直接下载 `static/index.html` 在浏览器中打开，或部署到静态托管 / GitHub Pages。

### 2. 热铁盒部署版
1. 将 `retiehe/` 目录下的全部文件与文件夹覆盖上传至热铁盒站点根目录。
2. 访问 `/api/kotonote.py?action=health` 验证云函数与 TTS 接口状态（返回 `"version": 4, "ttsReady": true` 即成功）。
3. 首次访问会自动初始化全部 187 条默认术语到云端 KV 数据库；从旧版升级不会丢失原有词库和便签。
